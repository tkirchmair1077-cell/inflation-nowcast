# Inflation Nowcast

This repository contains a simple inflation nowcasting dashboard and analysis project.

## Overview

Inflation nowcasting aims to estimate current inflation conditions using a combination of the latest available macroeconomic indicators, model signals, and lightweight analytics.

## Getting started

1. Clone the repository
2. Open the project in your preferred environment
3. Install dependencies as needed
4. Run the analysis or app
